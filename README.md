🚀 Getting Started

Follow these steps to explore and run the notebooks locally.

1. Clone the repository
git clone https://github.com/Nazim-Khan-2315/pandas_project.git

2. Navigate to the project directory
cd pandas_project

3. Create a virtual environment (recommended)
python -m venv .venv


Activate it:

Windows

.venv\Scripts\activate


macOS / Linux

source .venv/bin/activate

4. Install the required libraries

Install the core libraries:

python -m pip install pandas numpy jupyter matplotlib seaborn requests beautifulsoup4


These packages cover common data analysis, visualization, and web scraping tasks. Additional dependencies may be required depending on the notebook you choose to run.

5. Launch Jupyter Notebook
jupyter notebook


Open a notebook in your browser and run its cells sequentially.

Note: Some notebooks may require separate datasets, internet access, or additional dependencies. Check the individual notebook before running it.
